HTML & Markdown to PDF, built for AI agents

One POST request or one MCP tool call. No template editor, no template IDs, no dashboard. Send HTML or Markdown, get a clean PDF back. Markdown ships with a good default stylesheet, so agent-generated documents look right without any design work.

Try it now (no key needed)

curl -X POST https://pdfmint-production-0b25.up.railway.app/v1/pdf \
  -H "Content-Type: application/json" \
  -d '{"markdown":"# Invoice #42\n\nThanks for your business.","footerText":"Generated by PDFMint","pageNumbers":true}' \
  --output invoice.pdf

Anonymous requests: 5/day. Free key: 100/day — POST /v1/keys {"email":"you@example.com"}.

Use it from Claude or any MCP client

{
  "mcpServers": {
    "pdfmint": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://pdfmint-production-0b25.up.railway.app/mcp"]
    }
  }
}

Two tools: generate_pdf (HTML or Markdown in, download URL out) and pdf_from_url (public web page in, PDF out). Download URLs are valid for one hour.

API

EndpointWhat it does
POST /v1/pdfBody: one of html, markdown, url + options (format, landscape, margin, headerText, footerText, pageNumbers). Returns the PDF, or JSON with a link when "output":"url".
POST /v1/keysFree API key by email. No card, no verification loop.
POST /mcpMCP endpoint (streamable HTTP), same capabilities as the REST API.

Why not just self-host Gotenberg?

You can, and if you want to run and patch your own Chromium fleet, you should. PDFMint is for the other case: you (or your agent) need a PDF now, without deploying anything, and you want Markdown to come out looking good by default. We run the browsers, you send content.
