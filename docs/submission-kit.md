# Submission kit

Every product directory asks for the same eight things. Written once here so a submission takes a
minute instead of fifteen, and so the wording stays identical everywhere (consistency across listings
is itself a small ranking and trust signal).

**Standing rule: free queue only.** Most of these sell a "skip the queue" or "premium" tier. Buying it
buys a followed link, which is a link scheme, and it is the same offer already declined from mcp.so,
mcpservers.org, mcpmarket and Launch Llama. Being listed slowly is fine.

**Long description** (~400 chars, the common limit)
```
MintPDF turns Markdown or HTML into a finished PDF, or renders any public web page, and returns a
download link. There is no template editor and no dashboard: one POST request, or one MCP tool call
from an AI agent.

The work is in the print CSS. Tables and code blocks are not sliced across page breaks, table headers
repeat on every page, and text stays selectable rather than rasterised.

Free to try with no account. MIT licensed, and a container image is published so it can be self-hosted.
```
