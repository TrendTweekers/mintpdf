This page is what the API makes:
a finished document.

PDFMint turns HTML or Markdown into clean PDFs. One POST request, or one MCP tool call from Claude. No template editor, no template IDs, no dashboard. The page you are reading is typeset exactly like the API's Markdown output, because showing beats telling.

Try it, 10 seconds, no signup

curl -X POST https://pdfmint-production-0b25.up.railway.app/v1/pdf \
  -H "Content-Type: application/json" \
  -d '{"markdown":"# Invoice #42\n\nThanks for your business.","pageNumbers":true}' \
  --output invoice.pdf

Anonymous: 5 renders/day. Free key by email, no card: POST /v1/keys → 100/day.

From Claude, via MCP

Add one block to your MCP config; the agent writes Markdown and calls generate_pdf. You get a download link, valid one hour.

"pdfmint": {
  "command": "npx",
  "args": ["-y", "mcp-remote",
    "https://pdfmint-production-0b25
     .up.railway.app/mcp"]
}

Options: paper size, margins, landscape, headers, footers, page numbers. Chromium rendering, your CSS just works.

Honesty clause

If you want to run your own Chromium fleet, self-host Gotenberg; it is excellent and free. PDFMint is for when you need the document now, without deploying anything, and want Markdown to look right by default.

Pricing

Free while in beta; a free tier stays free afterwards. Planned Solo tier around $19/month for volume, beta users grandfathered. No per-seat pricing, no sales calls.
