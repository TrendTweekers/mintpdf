Markdown in, finished PDF out.

PDFMint is a PDF API for developers and AI agents. No template editor, no template IDs, no dashboard. This page is the entire product: read it top to bottom in four minutes and you know everything.

terminal — your first PDF, no signup
# 1. render markdown to a PDF
$ curl -X POST https://pdfmint-production-0b25.up.railway.app/v1/pdf \
    -H "Content-Type: application/json" \
    -d '{"markdown":"# Invoice #42\n\nThanks for your business.","pageNumbers":true}' \
    --output invoice.pdf

# 2. that's it
$ open invoice.pdf
→ 1 page · A4 · table styles, code blocks and headers already look right ✓

Use it from Claude

One block in your MCP config. Then ask for a PDF in plain language; the agent writes the Markdown and calls the tool.

claude_desktop_config.json
{
  "mcpServers": {
    "pdfmint": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://pdfmint-production-0b25.up.railway.app/mcp"]
    }
  }
}

Tools exposed: generate_pdf (HTML or Markdown → download URL, valid 1 hour) and pdf_from_url (public web page → PDF).

POST /v1/pdf

Body takes exactly one source plus options. Returns PDF bytes, or JSON with a download link when "output":"url".

FieldMeaning
htmlFull HTML document or fragment
markdownMarkdown, rendered with a clean default stylesheet
urlPublic http(s) page to render (private addresses blocked)

Options

OptionValues
formatA4 (default), Letter, Legal, A3, A5
landscapetrue / false
margine.g. "18mm", all sides
headerText / footerTextsmall print on every page
pageNumberstrue → "3 / 7" in the footer
Why not self-host Gotenberg? You can; it's excellent and free. PDFMint is for when you need a PDF now, without deploying anything, and want Markdown to come out looking good by default. We run the browsers, you send content.
